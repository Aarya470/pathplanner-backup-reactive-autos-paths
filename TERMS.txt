1. What this is
PathPlanner Backup Paths is a free, unofficial version of PathPlanner for the FIRST Robotics Competition. It adds backup paths: regions on a path that react to robots and game pieces during autonomous. It is based on PathPlanner by Michael Jansen and contributors. It is not made by, endorsed by, or supported by the PathPlanner project, FIRST, or any FRC sponsor.

2. Use at your own risk
This software plans paths that make a real robot move by itself. You are responsible for how your robot behaves. Test new or changed paths and backup paths at low speed, in a safe space, with someone ready to disable the robot. Follow your team's safety rules, the FRC game manual, and event rules. The author and FRC Team 1089 are not responsible for any damage, injury, penalty or lost match that comes from using this software.

3. No warranty
The software is provided "as is", without warranty of any kind. It may have bugs. Detection and backup path behavior depends on your camera, model, robot code and setup, and may not work the same on your robot.

4. Updates and internet use
The app checks GitHub for new versions when it starts, and can download and install updates when you ask it to. The robot library is downloaded from GitHub Pages through WPILib. No personal data is collected or sent.
